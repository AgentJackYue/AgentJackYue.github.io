# Oxidation Numbers and Chemical Nomenclature

本讲用氧化数描述化合物中电子的形式归属，并介绍离子、二元化合物、变价金属化合物、水合物和酸碱的系统命名方法。

## Oxidation Number

**oxidation number（氧化数）** 是假定化学键中的电子完全归属于电负性较大的原子后，某个原子所表现出的形式电荷。

- 氧化数是形式上的电子计数结果，不表示原子真实拥有的完整电荷。
- 对中性分子，所有原子的氧化数之和为 0。
- 对多原子离子，所有原子的氧化数之和等于离子的总电荷。

### Oxidation-Number Rules

1. 单质中元素的氧化数为 0。例如 $\mathrm{O_3}$ 中 O 为 0，$\mathrm{N_2}$ 中 N 为 0。
2. H 通常为 $+1$；与活泼金属形成 hydride（氢化物）时为 $-1$，例如 LiH 中 H 为 $-1$。
3. O 通常为 $-2$；在 peroxide（过氧化物）中为 $-1$，在 superoxide（超氧化物）中为 $-\tfrac12$。
4. F 在化合物中总为 $-1$。
5. 其他卤素通常为 $-1$，但与 O 或 F 成键时可以为正氧化数。
6. 周期表左下角元素更倾向形成正氧化数，右上角元素更倾向形成负氧化数。

![常见氧化数示例与周期表中的氧化数倾向](img/L02-Oxidation-Numbers-and-Chemical-Nomenclature/figure-01.png)

### Examples

| Species | Oxidation numbers | Reasoning |
|---|---|---|
| $\mathrm{O_3}$ | O = 0 | 单质 |
| $\mathrm{N_2O}$ | N = +1, O = −2 | 氧通常为 −2，总数必须为 0 |
| $\mathrm{HSO_4^-}$ | H = +1, O = −2, S = +6 | 总和为 −1 |
| $\mathrm{CuI}$ | Cu = +1, I = −1 | 碘化亚铜 |
| $\mathrm{LiH}$ | Li = +1, H = −1 | H 与活泼金属形成氢化物 |
| $\mathrm{ClO_4^-}$ | Cl = +7, O = −2 | 高氯酸根 |
| $\mathrm{OF_2}$ | O = +2, F = −1 | F 的电负性大于 O |
| $\mathrm{KO_2}$ | K = +1, O = −½ | 超氧化钾 |

在 $\mathrm{FeCl_3}$ 中，Cl 为 $-1$，因此 Fe 为 $+3$；在 $\mathrm{FeCl_2}$ 中，Fe 为 $+2$。

## Simple Ions and Ionic Compounds

- 单原子阳离子保留元素名称，例如 $\mathrm{Na^+}$ 是 sodium ion（钠离子）。
- 单原子阴离子通常在元素名后加 **-ide**，例如 $\mathrm{Cl^-}$ 是 chloride（氯离子），$\mathrm{O^{2-}}$ 是 oxide（氧离子）。
- 多原子离子具有独立名称，不能直接由元素名逐字拼出。

| Formula | Name | 中文名称 |
|---|---|---|
| $\mathrm{NH_4^+}$ | ammonium | 铵根离子 |
| $\mathrm{O_2^{2-}}$ | peroxide | 过氧根离子 |
| $\mathrm{O_2^-}$ | superoxide | 超氧根离子 |
| $\mathrm{ClO^-}$ | hypochlorite | 次氯酸根 |
| $\mathrm{ClO_2^-}$ | chlorite | 亚氯酸根 |
| $\mathrm{ClO_3^-}$ | chlorate | 氯酸根 |
| $\mathrm{ClO_4^-}$ | perchlorate | 高氯酸根 |
| $\mathrm{HCO_3^-}$ | hydrogen carbonate / bicarbonate | 碳酸氢根 |
| $\mathrm{H_2PO_4^-}$ | dihydrogen phosphate | 磷酸二氢根 |
| $\mathrm{Cr_2O_7^{2-}}$ | dichromate | 重铬酸根 |

![简单离子、含氧酸根和过氧化物离子的命名](img/L02-Oxidation-Numbers-and-Chemical-Nomenclature/figure-02.png)

### Ionic-Compound Formulas

离子化合物必须满足整体电中性：

$$
\sum_i q_i n_i=0
$$

式中 $q_i$ 是第 $i$ 种离子的电荷，$n_i$ 是其数目。

- $\mathrm{Ca^{2+}}$ 与 $\mathrm{OH^-}$ 以 $1:2$ 结合，得到 $\mathrm{Ca(OH)_2}$。
- $\mathrm{Al^{3+}}$ 与 $\mathrm{O^{2-}}$ 以 $2:3$ 结合，得到 $\mathrm{Al_2O_3}$。
- $\mathrm{Ag^+}$ 与 $\mathrm{Br^-}$ 以 $1:1$ 结合，得到 $\mathrm{AgBr}$。

## Greek Prefixes in Molecular Names

共价分子通过 Greek numerals（希腊数字前缀）表示原子数目：

| Number | Prefix | Number | Prefix |
|---:|---|---:|---|
| 1 | mono- | 6 | hexa- |
| 2 | di- | 7 | hepta- |
| 3 | tri- | 8 | octa- |
| 4 | tetra- | 9 | nona- |
| 5 | penta- | 10 | deca- |

- $\mathrm{CO}$：carbon monoxide（一氧化碳）
- $\mathrm{CO_2}$：carbon dioxide（二氧化碳）
- $\mathrm{N_2O_4}$：dinitrogen tetroxide（四氧化二氮）
- $\mathrm{P_2O_5}$：diphosphorus pentoxide（五氧化二磷）
- $\mathrm{SF_6}$：sulfur hexafluoride（六氟化硫）
- $\mathrm{P_4}$：tetraphosphorus（四磷）

当名称不至于产生歧义时，第一个元素的 **mono-** 可以省略，例如 $\mathrm{CO}$ 写作 carbon monoxide，而不是 monocarbon monoxide。

## Naming Metals with Variable Oxidation States

具有固定氧化数的金属直接使用元素名称；具有可变氧化数的金属需要在名称中注明价态。

### Traditional Nomenclature

传统命名使用拉丁词根：

- 较高氧化数使用 **-ic**；
- 较低氧化数使用 **-ous**。

| Formula | Traditional name | Oxidation state | 中文名称 |
|---|---|---:|---|
| $\mathrm{FeCl_3}$ | ferric chloride | Fe +3 | 氯化铁 |
| $\mathrm{FeCl_2}$ | ferrous chloride | Fe +2 | 氯化亚铁 |
| $\mathrm{CuO}$ | cupric oxide | Cu +2 | 氧化铜 |
| $\mathrm{Cu_2O}$ | cuprous oxide | Cu +1 | 氧化亚铜 |
| $\mathrm{SnCl_4}$ | stannic chloride | Sn +4 | 氯化锡 |
| $\mathrm{SnCl_2}$ | stannous chloride | Sn +2 | 氯化亚锡 |

![固定价态与可变价态金属的传统命名规则](img/L02-Oxidation-Numbers-and-Chemical-Nomenclature/figure-03.png)

### Stock Nomenclature

**Stock nomenclature（Stock 命名法）** 用罗马数字直接标明金属氧化数：

- $\mathrm{FeCl_3}$：iron(III) chloride；
- $\mathrm{FeCl_2}$：iron(II) chloride；
- $\mathrm{CuI}$：copper(I) iodide；
- $\mathrm{CuO}$：copper(II) oxide；
- $\mathrm{LiFePO_4}$：lithium iron(II) phosphate。

罗马数字是氧化数，不是原子个数。例如 copper(II) sulfate 中的 II 表示 Cu 为 $+2$，而化学式中实际有多个 O 原子。

## Systematic Nomenclature

系统命名优先表达明确的组成信息：

- $\mathrm{O_3}$：trioxygen（三氧）
- $\mathrm{N_2O}$：dinitrogen oxide 或 nitrogen(I) oxide
- $\mathrm{HSO_4^-}$：hydrogen sulfate（硫酸氢根）
- $\mathrm{CuSO_4\cdot5H_2O}$：copper(II) sulfate pentahydrate（五水合硫酸铜(II)）
- $\mathrm{Hg_2Cl_2}$：mercury(I) chloride 或 dimercury dichloride
- $\mathrm{D_2O}$：deuterium oxide（氧化氘）

![系统命名法中的氧化数、希腊数字和水合物](img/L02-Oxidation-Numbers-and-Chemical-Nomenclature/figure-04.png)

### Acids

二元酸通常使用 **hydro-** 加元素词根再加 **-ic acid**：

- $\mathrm{HBr(aq)}$：hydrobromic acid（氢溴酸）
- $\mathrm{HCl(aq)}$：hydrochloric acid（盐酸）

含氧酸及其 salt（盐）可按含氧数目的系列命名：

| Acid | Anion | Naming relation |
|---|---|---|
| $\mathrm{HClO}$ | $\mathrm{ClO^-}$ | hypochlorous acid / hypochlorite |
| $\mathrm{HClO_2}$ | $\mathrm{ClO_2^-}$ | chlorous acid / chlorite |
| $\mathrm{HClO_3}$ | $\mathrm{ClO_3^-}$ | chloric acid / chlorate |
| $\mathrm{HClO_4}$ | $\mathrm{ClO_4^-}$ | perchloric acid / perchlorate |

高碘酸可写作 iodic(VII) acid 或 periodic acid，对应 $\mathrm{HIO_4}$。

## Hydrates

**hydrate（水合物）** 的化学式用中心点连接结晶水：

$$
\mathrm{CuSO_4\cdot5H_2O}
$$

其名称为 copper(II) sulfate pentahydrate。中心点前的化学式单元与结晶水的数目必须分别读出；“pentahydrate”表示每个化学式单元含 5 个 $\mathrm{H_2O}$。

## Common Naming Errors

- **oxidation number** 和 subscript（下标）都是数字，但意义不同：罗马数字和“-ic/-ous”描述价态，元素右下角数字描述粒子数目。
- peroxide $\mathrm{O_2^{2-}}$、superoxide $\mathrm{O_2^-}$ 和 oxide $\mathrm{O^{2-}}$ 不能混为一谈。
- 对离子化合物，要先确定离子电荷，再配平整体电中性。
- 对共价分子，只有名称确实需要时才使用希腊数字前缀。
- 传统名称 ferric/ferrous 等仍然常见，但 Stock 名称在跨语言交流时更直接。
