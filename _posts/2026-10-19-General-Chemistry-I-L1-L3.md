Heterogeneous 非均相 体系中存在两个或更多不同的相，具有可区分的界面。例子：油和水、冰水混合物、固体与气体共存的体系。

## 1. Binary Ionic Compounds（二元离子化合物）

由金属阳离子和非金属阴离子组成。

命名规则：金属名称 + 非金属词根 + -ide

| 化学式 | 英文名称 | 中文名称 |
|---|---|---|
| NaCl | Sodium chloride | 氯化钠 |
| MgO | Magnesium oxide | 氧化镁 |
| CaBr₂ | Calcium bromide | 溴化钙 |
| Al₂S₃ | Aluminum sulfide | 硫化铝 |

常见非金属阴离子的命名变化：

| 元素 | 阴离子名称 |
|---|---|
| F（fluorine） | Fluoride |
| Cl（chlorine） | Chloride |
| O（oxygen） | Oxide |
| S（sulfur） | Sulfide |
| N（nitrogen） | Nitride |
| Br（bromine） | Bromide |

## 2. Transition Metals（过渡金属）

部分金属可以形成不同电荷的离子，因此需要用罗马数字标明金属的氧化态。

| 化学式 | 英文名称 | 金属氧化数 |

| FeCl₃ | Iron(III) chloride | Fe = +3 |
| Cu₂O | Copper(I) oxide | Cu = +1 |

## 4. Acids（酸的命名）

基础课程中常见的酸包括以下几类。

| 化学式 | 英文名称 | 中文名称 |
|---|---|---|
| HCl(aq) | Hydrochloric acid | 盐酸 |
| H₂SO₄ | Sulfuric acid | 硫酸 |
| H₂SO₃ | Sulfurous acid | 亚硫酸 |
| HNO₃ | Nitric acid | 硝酸 |
| HNO₂ | Nitrous acid | 亚硝酸 |
| H₃PO₄ | Phosphoric acid | 磷酸 |

含氧酸的命名规律：

- 多原子阴离子以 -ate 结尾时，酸通常以 -ic acid 结尾。
  - Sulfate → Sulfuric acid
  - Nitrate → Nitric acid
- 以 -ite 结尾时，酸通常以 -ous acid 结尾。
  - Sulfite → Sulfurous acid
  - Nitrite → Nitrous acid

HCl 需要注意状态：HCl(g) 是 hydrogen chloride（氯化氢），而 HCl(aq) 是 hydrochloric acid（盐酸）。

### 4. Naming Rules（命名规则）

1. 前缀表示原子数量：di- = 2，tri- = 3，tetra- = 4，以此类推。
2. 第一个元素为 1 个原子时，通常省略 mono-：CO₂ 叫 carbon dioxide，而不是 monocarbon dioxide。
3. 第二个元素通常以 -ide 结尾：oxide、sulfide、fluoride。
4. 遇到元音时，部分前缀会省略末尾的 a 或 o：
   - mono- + oxide → monoxide（一氧化物）
   - tetra- + oxide → tetroxide（四氧化物）
   - penta- + oxide → pentoxide（五氧化物）

# Lecture 4
Vacuum level 真空能级
真空能级指电子在脱离任何其它物质完全自由状态下的能量（在完美真空中）.势能高.
相对应的是,被限制的能级 势能低.

## The Bohr Model
Planck’s Law 普朗克定律
- 能量只能取离散值
- 能量以量子为单位吸收或释放
\[
\boxed{\Delta\varepsilon=h\nu}
\]

  \(\Delta\varepsilon\)：一次能量跃迁对应的能量差。
  \(h\)：普朗克常数，约为 \(6.626\times10^{-34}\ \mathrm{J\cdot s}\)。
  \(\nu\)：频率，单位为 Hz。

- 温度足够高，才能激发高能级
这里的逻辑是：
  - 低温： 系统中的振子较难获得较大的能量，较高能级不容易被占据。
  - 高温： 更多振子能够处于较高能级，因此可以发生更多高能量的跃迁。
  - 振子从高能级跃迁到低能级时，可以释放能量。

Bohr Model（玻尔原子模型）
玻尔模型主要用来解释氢原子的能级为什么是离散的，以及原子为什么会发射或吸收特定频率的光。它把你刚学的 Planck 量子化思想应用到了原子结构中。
一、核心公式
对于氢原子或类氢离子（只有一个电子，例如 \(\mathrm{He^+}\)、\(\mathrm{Li^{2+}}\)），有以下几个常用公式。
1. 电子的能级（Energy levels）
\[
\boxed{E_n=-\frac{13.6Z^2}{n^2}\ \mathrm{eV}}
\]

- \(n=1,2,3,\ldots\)：主量子数（principal quantum number）。
- \(Z\)：原子核的电荷数，例如 H 的 \(Z=1\)，\(\mathrm{He^+}\) 的 \(Z=2\)。
- \(E_n\)：第 \(n\) 个能级的能量。

与之相对，振幅最大的地方称为 Antinode（波腹）。

oscillatory part 振荡部分

公式	含义	主要用途
\(E=h\nu\)	光子能量与频率的关系	光电效应、光子能量计算
\(E=mc^2\)	质能关系	理解质量与能量的联系
\(p=mv\)	经典力学中的动量定义	引出动量概念，但不能直接当作光子的公式
\(c=\lambda\nu\)	真空中光的波速关系	联系波长、频率和光速

\[
p=\frac{h\nu}{c}
\]

而真空中光速满足 \(c=\lambda\nu\)，即 \(\nu/c=1/\lambda\)，所以最终得到：
\[
\boxed{p=\frac{h}{\lambda}}
\]

这就是光子的动量公式。
